# Reel kit

Everything you need to edit the GTA VI petition reel in CapCut (or InShot, VN, Instagram Edits).

## What's in here
- `overlays/`: 16 transparent text graphics (1080×1920 PNG). Drop each one on top of your footage.
- `clips/petition_scroll.mp4`: 11s phone screen recording scrolling through the petition.
- `clips/petition_sign.mp4`: 15s phone screen recording of someone signing (demo name "Alex Rivera"), the "You're in" screen and the counter going up.
- `reel-kit.zip`: all of the above in one download.

## How to make them "flash" in CapCut
1. Import your footage. Tap **Overlay → Add overlay** and pick a PNG. It covers the full screen, so no resizing needed.
2. Trim it to the 1–3 seconds it should show.
3. Tap **Animation → In → Pop** (or Zoom in / Bounce), set it to 0.2–0.3s. Out: **Fade out**, 0.2s.
4. Add a **whoosh** or **pop** sound effect at the start of each overlay (Audio → Sound effects).
5. For the screen recordings: add them as a main clip (full screen), or as an overlay shrunk to about 70% inside a phone-shaped frame with you behind them.
